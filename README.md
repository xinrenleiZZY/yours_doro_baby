# doro_dz 桌面宠物

一只住在 Windows 桌面上的 doro：会自己换着花样演小动作，同时每秒给你产金币。
透明无边框窗口 + 托盘常驻，不抢任务栏，不挡鼠标（点击穿透）。

## 功能

- **AI 陪伴与动作联动**：右键 →「和 doro 聊天」或按 `Ctrl+Alt+C` 打开独立聊天窗，支持 DeepSeek、OpenAI、Ollama 等 OpenAI-compatible 接口。回复会结合当前心情、饱食、亲密度和性格，同时生成受约束的情绪 / 手势意图，再由本地动作库执行；模型不能直接操作电脑。
- **陪伴式聊天界面**：真实 doro 头像、连接状态、插画空状态、快捷开场与底部紧凑输入栏；设置卡发送消息时自动收起。
- **局域网好友、聊天与群组**：右键 →「社交与排行榜」，自动获得 `doro_xxxxxxxx` 游戏 ID，可设置昵称和简介、搜索玩家、发送/接受好友申请并查看在线状态。好友之间可私聊；群组支持邀请好友、50 人群聊、改名、移出成员、退出与解散。同一窗口的「排行榜」展示等级、家具、时装、典藏四榜，并在北京时间每天 00:00 为榜一发放限定典藏。
- **安全配置与短期会话**：API Key 通过 Electron `safeStorage` 加密保存在主进程，不进入渲染界面和普通存档；最近 30 轮对话保存在本机，可随时清空。持续使用电脑约一小时后，doro 会提醒起身休息，勿扰模式下不主动打扰。
- **295 个动作**：日常、情绪、吃睡、玩乐、打工、换装、小剧场、表情包 8 大类。右键 →「动作库」，支持搜索、分类、收藏、最近使用、分页；换装动作需要用金币解锁；枪械 / 泳装 / 纯黑等标记为「不参与随机」。
- **每秒产金币**：基础产出由境界等级与大境界加成共同决定，再乘心情、饱食、性格、资产与榜一效果；饿了只打折（40%），饿到底也保留 20%，不会停产。
- **完整灵根谱系**：开局随机单灵根、双灵根、三灵根、四灵根、五灵根、冰 / 雷 / 光 / 暗 / 混沌变异灵根或先天道体，共 37 类。单灵根为 1 倍修炼基准，双、三、四、五灵根依次降至 0.6–0.7、0.4、0.25、0.1 倍；变异灵根为 5–10 倍，并降低天劫强度。相生双灵根更稳定，相克组合更容易卡关。
- **修仙成长**：随机灵根、悟性、福缘、道心和寿元共同决定成长路线；用金币购买灵石修炼，随机获得修为或毫无进展。小境界自动晋升，大境界圆满后必须满足修为、丹药 / 心魔试炼、功法领悟、悟性与道心条件才能突破。悟性、福缘、道心、基础寿元和功法领悟上限统一开放至 **99999**。
- **独立境界面板**：境界、资质、寿元、灵石、打坐、阵法、突破、洞天福地和转世集中在「境界与突破」面板；任务、亲密度、日记、图鉴、签到、打工与成就继续保留在「任务与成就」面板。
- **橘子大陆**：新角色从橘子大陆的三个初始区域随机出生；大陆共 12 个区域，按等级解锁并拥有不同灵气浓度、灵药、灵石品质和修炼风险。
- **固定能量灵石与打坐**：下品 / 中品 / 上品 / 极品灵石分别最多提供 10 / 100 / 1000 / 10000 点能量，玩家等级不会放大灵石能量；购买数量和单次修炼消耗数量均可自定义至 9999。可随时打坐吐纳，速度受区域灵气、灵根、悟性、阵法影响，离线最多结算 12 小时。灵石批量吸收和打坐都可主动提前结束，灵石按已吸收比例结算。
- **洞天福地**：共有 10 处，每两小时轮换一次，每轮随机 1–3 处大型福地。玩家可查看灵气倍率和随机效果后选择前往，每次消耗 1 枚下品灵石并获得 30 分钟修炼增益。大型福地有 75% 概率遭遇守灵：避战降低 80% 掉落率，观望降低 50%，战斗提高 20% 并可能大量增加或损失修为。小型福地也会随机产出功法和丹药；进入后可随时主动离开，守灵挑战也会一并放弃。
- **生命、攻击与防御**：生命按每级约 ×1.08、攻击约 ×1.075、防御约 ×1.07 的复利曲线成长，并叠加悟性、道心、寿元、功法与根骨修正；属性会直接参与黑塔战斗。生命低于 20% 会自动退出黑塔；打坐、灵石修炼和静养均可缓慢恢复生命。
- **灵力与黑塔挑战**：灵力上限按当前修为与此前各小境修为需求总和成长；灵力会随区域灵气、阵法、功法、洞天和修为效率缓慢恢复，进度显示在修为条正下方。黑塔迁入独立窗口，共 10 层并按境界解锁；每层包含 100 只小怪与 1 名守护者，击杀 70 只后守护者出现，需清空小怪并击败守护者才能通关。小怪每秒攻击一次，玩家可能防御成功、闪避或受伤；支持前往下一层、自动通关、循环刷本、暂停与战斗记录。
- **辟谷与元婴维持**：辟谷丹可持续现实一日（修仙界一年）不消耗饱食度。元婴期后永久辟谷，不再需要食物或受饥饿产出惩罚，改为持续消耗灵力；维持量为不计环境的基础恢复量 ×1.2，环境恢复同时结算，打坐可降低 90% 维持消耗。
- **培元丹阶段额度**：培元丹仍提供当前小境界 8%–16% 修为，但每个小阶段最多服用 2 颗，升级后进入新阶段并重置额度；面板和背包都会显示本阶段已用次数。
- **功法分类与多修**：37 类灵根各有天、地、玄、黄四阶、上中下三品，共 444 部功法，分为心法、法术、战技、身法、体术五类。每类可同时修炼一部，最多多修五部；每部功法独立累计 0–100 进度，可通过灵石修炼、打坐、重温卷轴和定向参悟提升。多部功法加成会共同生效。商城「功法」分类可购买本命灵根卷轴；非本命灵根功法标记为「异灵根」并禁止购买，混沌灵根和先天道体可兼容全部功法。
- **功法背包**：独立背包支持按五类功法筛选、查看单部进度条、开始 / 暂停修炼、重温卷轴与指定参悟；丹药页包含破境丹、延寿丹、悟道丹、培元丹、静心丹和避雷珠，灵石与灵药统一管理。
- **机缘录**：新增数据驱动的修仙事件系统，首批 30 个原创事件和 60 个抉择。事件会按境界、区域、灵根、属性、资源及前置剧情筛选，选择可触发福缘修正的成功 / 失败分支，并记录到独立的「机缘录」窗口。每次寻缘冷却 20 分钟，支持单次事件和连续剧情。
- **功法领悟**：炼气期后可主动“参悟功法”，成功提高功法领悟并进入 5 分钟冷却；打坐也会缓慢积累功法领悟，灵石修炼成功则少量增加。已装备功法会提高修炼效率、功法领悟收益与后续破境成功率。
- **寿元与轮回**：现实 1 天折算修仙界 1 年，寿元耗尽会陨落并清空本世进度、重选天赋；元婴期可主动转世，并尝试携带灵根、悟性、福缘、道心或寿元之一，50% 概率叠加继承、50% 被新命格覆盖。
- **仙人神魂转世**：Lv.101 后可保留对应等级的前世神魂与灵根；神魂按前世灵根提供全属性加成，今生若生成同源灵根会进一步提升灵根等阶。
- **境界权限**：炼气可采集灵药，筑基可炼丹，金丹可进入秘境；更高境界继续开放飞行、神魂探查、瞬移与仙阶权限。
- **商城**：食物 / 修炼 / 功法 / 玩具 / 增益 / 主题 / 家具 / 装扮 / 典藏九类货物。修炼分类可批量购买四档灵石、五种丹药和避雷珠，购买数量与修炼消耗数量均可自定义至 9999；功法分类可购买本命灵根功法卷轴。食物、玩具和功法卷轴买进背包、使用后生效；限时增益购买后立即生效并显示剩余时间；家具和装扮可选 1 / 3 / 7 / 30 日或永久。商品目录由 Docker 提供并缓存到本机，改价格、积分、加成或上下架不需要重新打包客户端。
- **11 款限时增益**：提神咖啡与柠檬气泡水、蜂蜜能量棒、抹茶拿铁、能量饮料、夜猫子特调、幸运四叶草、云端香薰、星河护符、摸鱼大师茶、时光胶囊；效果持续 10–45 分钟，产出 ×1.25–×3，多款同时生效时采用最高倍率。
- **Docker 商城权益**：永久购买和租赁到期时间同步到 Docker，同时保留本地缓存；现有永久资产首次同步自动合并。金币、心情、等级和动作进度仍只保存在本机。
- **家具与典藏扩容**：商城现有 31 件家具和 32 件典藏，包含森林许愿池、星轨留声机、doro 永恒宇宙、宇宙尽头咖啡厅等高阶商品。
- **20 款叠层装扮**：两批服装均可直接叠加在任意宠物动作上，第二批包含蝶翼发夹、云朵耳罩、草莓发带、月光耳坠、铃铛项圈、水晶小皇冠、兔兔背包、彩虹披风、星星眼罩和月纱头饰；购买后自动穿戴，可穿脱并参与时装榜。
- **性格与典藏**：五种性格会影响产出、互动心情和随机动作；每只 doro 有固定喜欢 / 不喜欢的食物玩具。商城「典藏」提供多档永久产出藏品、性格重塑卡和偏好重置券；四件榜一限定典藏不可直接购买。
- **每日排行榜**：等级榜按当前转世后的境界等级计分；家具榜和时装榜只计算有效期内的租赁或永久资产，典藏榜按永久藏品汇总。服务端使用 `Asia/Shanghai` 自然日，00:00 定榜并给四个榜一分别发放对应限定典藏。
- **榜一「永耀」**：榜一定榜后，下一天对应榜单有效分数 +20%，到再下一次 00:00 自动失效。等级榜第一名另有永久产出 +5%，并且当日永耀产出为 +100%；家具、时装、典藏榜的当日永耀产出为 +200%。多个榜单同时夺冠会分别叠加。
- **训练与招式**：新 doro 从 4 个基础动作起步，其余普通动作通过摸头、喂饭、陪玩和接金币积累训练点后，在动作库「可训练」分类中逐个学习；旧存档会按历史图鉴、收藏和最近使用补偿已学招式。
- **派遣打工**：访客或伙伴 doro 可派去 2 / 4 / 8 小时打工，离线结束带回金币、食物或装扮碎片；伙伴打工期间会暂时离开桌面。该功能为本地循环，不需要好友系统。
- **转世重修**：元婴期（Lv.41）后可消耗二次确认转世，当前等级、金币和本世资产清空，命格重新生成，并按 50% 概率决定所选属性是否叠加继承。
- **亲密度与桌面日记**：互动、心愿和访客会提升独立于心情的亲密度，分阶段解锁专属台词、动作和装扮；跨天自动生成前一天的金币、动作和访客日记。系统空闲 10 分钟会睡觉，回来后伸懒腰，并支持整点报时。
- **任务与成就**：每日任务（摸头 / 喂饭 / 陪玩 / 换动作）和 8 个成就，达成后领金币；商城新增夜行 / 薄荷 / 樱花三套主题，给金币提供长线消耗。
- **图鉴 / 心愿 / 签到**：看过的动作会点亮图鉴（295 个分 8 类统计）；随机心愿限时完成给金币；每日签到按连续天数发奖；境界显示为凡人、炼气、筑基直至仙帝，并细分初期 / 中期 / 后期 / 圆满。
- **动作库管理（增删改查）**：覆盖动作库全部 295 个动作的搜索、预览、收藏、改名、随机开关和批量策略。可以导入自己的 GIF / WebP / PNG 动作图片（≤8MB，最多 200 个）；内置动作删除只隐藏，之后可「下载内置」恢复，自定义动作执行真实删除。
- **独立工具窗口**：商城、扭蛋机、接金币和动作库管理都使用与题库一致的无边框可拖动窗口，不再改变宠物窗口尺寸；交易由主进程统一校验并同步到同一份存档。
- **工具窗自适应**：独立窗口支持 460px 至 900px 以上宽度，表情网格自动换列，商城自动收缩，扭蛋和小游戏随宽高调整。
- **动作库缩放**：动作库支持标题栏放大/缩小按钮和右下角拖拽缩放，网格按宽度自动换列，关闭后恢复宠物窗口原尺寸。
- **扭蛋 / 存钱罐 / 接金币**：500 金币抽一次（金币 / 食物玩具 / 永久装扮 / 主题 / 1–7 天限时家具和装扮）；限时资产到期自动失效，重复抽到同一件会续期。金币可存 8 小时吃 15% 利息；15 秒接金币小游戏，每枚金币 +10,000，冷却 5 分钟。
- **豪华扭蛋奖池**：单抽 500、十连 4,500，最高可获得 **1,000 万金币**；另有 5 千 / 5 万 / 50 万三档大奖，80 抽保底至少 5 千金币。
- **访客 / 房间 / 伙伴**：小猫、鸽子或另一只 doro 会定期来访，点一下接待拿奖励；商城可买家具有永久产出加成；领养伙伴 doro 会出现在桌面上并 +8% 产出。
- **日程表**：按时间添加提醒（每天 / 工作日 / 周末 / 仅一次，最多 20 条），支持延后 10 分钟；到点 doro 会说话 + 播放动作 + 弹系统通知，点击通知唤出宠物。
- **题库答题**：右键菜单 →「学习」进入题库。每日一题（答对 +10,000 / 答错不扣）、随堂小测 10 题（对 +10,000 / 错 -100）、随机刷题（对 +10,000 / 错 -100）、答题事件（对 +10,000 / 错不扣，冷却 20 分钟）、模拟考试（150 分钟 / 75 题，可续考）。默认题库「系统架构设计师」，可在题库面板切换，服务地址在配置中心修改。取题与判卷都在主进程，客户端拿不到答案。
- **自动更新**：局域网 Docker 静态源（`update-server/`，端口 9400）。每天 08:00 与启动后自动检查；doro 右键菜单新增「更新新版本」，会显示检查、下载进度和安装状态，并与托盘使用同一套检查 → 下载 → 重启安装流程。也可在配置中心手动检查。
- **本地统计**：可选开启，记录累计天数、今日在线时长、会话次数，只存本机不上传。
- **配置中心**：动作频率（5–600 秒，默认 60 秒 ±25%）、自动散步间隔、宠物大小（70%–150%）、安全模式、音效、气泡 / 散步 / 穿透 / 置顶开关，支持恢复默认，改动即时生效并自动保存。可开启自动购买并进食；显示 / 隐藏、召唤、打开聊天三组全局快捷键都可在配置中心重新录制并即时注册。
- **离线收益**：关掉以后再打开，按离线时长 5 折结算，最多结算 8 小时。
- **互动**：点一下摸头（掉 1~2 金币 + 台词）、双击贴贴、拖拽移动、**甩出去会带着惯性飞一段并反弹落地**、右键菜单换常驻动作。
- **自主漫游**：像 Shimeji 一样在桌面上走走停停、到边缘折返、朝向自动翻转；可调漫游速度，可选「跟随鼠标」。
- **全局快捷键**：默认 `Ctrl+Alt+D` 显示/隐藏、`Ctrl+Alt+R` 召唤到鼠标位置、`Ctrl+Alt+C` 打开聊天，均可在配置中心自定义。
- **自动行为**：平时每隔 60 秒（可调）随机演一个动作；心情好爱演开心的，饿的时候只演惨的；「勿扰模式」下不表演、不说话、不弹提醒。
- **托盘**：喂饭 / 陪玩 / 换动作 / 置顶 / 点击穿透 / 开机自启 / 打开存档与日志 / 退出。
- **存档**：15 秒兜底自动存档 + 操作后防抖存档，白名单校验后原子写入；修仙成长存档为 v30。每次旧版迁移前会先备份到 `save-backups/`，商城权益额外同步到 Docker。

## 快速开始

```powershell
npm install      # 安装依赖（含 Electron）
npm start        # 启动桌面宠物
npm run dev      # 带 DevTools 启动
```

首次启动会在屏幕右下角出现 doro，并在托盘生成图标。右键 doro 或左键点金币胶囊都能打开面板。

## AI 聊天配置

1. 右键 doro →「和 doro 聊天」，或按 `Ctrl+Alt+C`。
2. 点聊天窗右上角 `⚙`，填写兼容接口的 Base URL、模型名称和 API Key。
3. 可先点预设填入 DeepSeek / OpenAI / Ollama 的常用地址，再按实际服务修改。
4. 保存后直接输入消息；首次未配置时聊天窗会自动展开设置。

常用配置示例：

| 服务     | Base URL                      | 模型示例         |
| -------- | ----------------------------- | ---------------- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat`  |
| OpenAI   | `https://api.openai.com/v1`   | 账号可用的模型名 |
| Ollama   | `http://127.0.0.1:11434/v1`   | 已下载的本地模型 |

聊天只携带宠物状态、时间和最近对话，不默认读取屏幕、键盘、剪贴板或其它应用正文。若要接入局域网中转服务，同样填写它的 OpenAI-compatible Base URL。

## 局域网好友服务

```powershell
docker compose -f social-server/docker-compose.yml up -d --build
```

默认地址：`http://192.168.0.193:9500`，健康检查：`/health`。好友、私聊与群聊消息、群成员、已读状态、排行榜、商城权益和恢复码哈希保存在 `social-server/data/social.json`；商城目录在 `social-server/shop-catalog.json`，修改后服务会按文件更新时间重新加载。

打开桌面宠物的「社交与排行榜」即可创建身份。好友页可进入私聊；聊天页每 4 秒同步会话和未读；群组页用于创建群、邀请好友和管理成员。私聊只允许好友访问，群聊只允许群成员访问，非成员无法读取会话内容。资料页的「商城云存档」可查看目录版本并立即同步。新电脑选择“恢复已有身份”，输入原来的游戏 ID 和恢复码即可取回 Docker 中的商城权益；恢复码使用后会轮换，务必在旧设备仍可用时复制保存。

## 更新发布

`package.json` 的 `build.publish` 指向局域网更新源 `http://192.168.0.193:9400/updates`。
发布新版本的步骤：

1. 提升 `package.json` 的 `version`；
2. `npm run dist` 生成 `release/`（含 `latest.yml` 与安装包）；
3. 启动更新服务：`cd update-server && docker compose up -d --build`；
4. 客户端每天 08:00 自动检查，托盘「发现新版本」点击即自动下载安装。

详细说明见 [`update-server/README.md`](update-server/README.md)。

## 素材处理

`doro_dz/` 里的 GIF 是白底，直接放到桌面上会带一个白框。整套流水线是：

```powershell
npm run assets:library   # 按命名表重命名源文件，生成 tools/action-library.json
npm run assets           # GIF → 透明 WebP + assets/actions.json
npm run assets:thumbs    # 生成动作库缩略图
```

`tools/prepare_assets.py` 会：

1. 把每帧最长边缩到 300px、WebP 质量 70，控制体积（295 个动作约 49MB）；
2. 从画布四边做洪水填充，只删掉与边缘连通的白色背景，保留 doro 身体内部的白色；
3. 对 alpha 做轻微羽化，避免锯齿；
4. 按所有帧的并集裁边，让不同动作里的 doro 看起来一样大；
5. 输出带透明通道的动画 WebP 和 `assets/actions.json`，并用待机帧生成托盘图标。

首次使用先装依赖：`pip install -r requirements.txt`。三个 `assets` 脚本都会自动寻找
`py -3` / `python` / `python3`，也可以用环境变量 `DORO_PYTHON` 指定解释器。

## 常见问题

**启动时报 `Sandboxed processes cannot read ... electron\dist`**

Windows 的某些数据盘（例如这台机器上的 `E:\`）没有给 `ALL APPLICATION PACKAGES` 授予读权限，Electron 的沙箱检查会拒绝启动。按提示给依赖目录补一次只读权限即可（只需执行一次）：

```powershell
icacls ".\node_modules\electron\dist" /grant "*S-1-15-2-1:(OI)(CI)(RX)" /T /C /Q
```

**doro 挡住了别的窗口？**

菜单 → 设置 → 打开「点击穿透」。开启后菜单会自动收起；鼠标只在 doro 本体、金币胶囊、账本面板和右键菜单上生效，其余透明区域直接落到桌面上。命中判定由主进程轮询光标完成（不依赖系统转发），如果哪天真的点不到，可以用托盘菜单里的同名开关关掉。

**想让它开机自启？**

菜单 → 设置 → 「开机自启」，或托盘菜单同名开关（写入系统登录项，可随时关闭）。
