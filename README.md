# doro_dz 桌面宠物

一只住在 Windows 桌面上的 doro：会自己换着花样演小动作，同时每秒给你产金币。
透明无边框窗口 + 托盘常驻，不抢任务栏，不挡鼠标（点击穿透）。

## 功能

- **295 个动作**：日常、情绪、吃睡、玩乐、打工、换装、小剧场、表情包 8 大类。右键 →「动作库」，支持搜索、分类、收藏、最近使用、分页；换装动作需要用金币解锁；枪械 / 泳装 / 纯黑等标记为「不参与随机」。
- **每秒产金币**：`每秒产出 = 等级 × (1 + 0.5 × 心情/100)`；饿了只打折（40%），饿到底也保留 20%，不会停产。
- **养成闭环**：喂饭（20 金币，+30 饱食）、陪玩（30 金币，+25 心情）、搬砖升级（永久提高产出，越升越贵）。
- **商城**：食物 / 玩具 / 增益 / 主题 / 家具 / 装扮 / 典藏七类货物。食物和玩具买进背包、用掉才生效；咖啡 10 分钟产出 ×1.5；招财猫永久 +10%；装扮解锁后才能在动作库选用。
- **性格与典藏**：五种性格会影响产出、互动心情和随机动作；每只 doro 有固定喜欢 / 不喜欢的食物玩具。商城「典藏」提供最高 250 万金币的永久产出藏品，以及性格重塑卡和偏好重置券。
- **任务与成就**：每日任务（摸头 / 喂饭 / 陪玩 / 换动作）和 8 个成就，达成后领金币；商城新增夜行 / 薄荷 / 樱花三套主题，给金币提供长线消耗。
- **图鉴 / 心愿 / 签到**：看过的动作会点亮图鉴（295 个分 8 类统计）；随机心愿限时完成给金币；每日签到按连续天数发奖；等级附带「摸鱼实习生 → 摸鱼合伙人」称号。
- **表情包管理（增删改查）**：50 个内置表情包可预览、收藏、改名，并逐个开关「是否参与随机」；支持全部随机 / 全部禁止 / 仅收藏。可以导入自己的 GIF / WebP / PNG 表情包（≤8MB，最多 200 个），自定义表情包可删除，内置的不可删除。
- **独立工具窗口**：商城、扭蛋机、接金币和表情包管理都使用与题库一致的无边框可拖动窗口，不再改变宠物窗口尺寸；交易由主进程统一校验并同步到同一份存档。
- **扭蛋 / 存钱罐 / 接金币**：500 金币抽一次（金币 / 食物玩具 / 未解锁装扮 / 主题）；金币可存 8 小时吃 15% 利息；15 秒接金币小游戏，冷却 5 分钟。
- **访客 / 房间 / 伙伴**：小猫、鸽子或另一只 doro 会定期来访，点一下接待拿奖励；商城可买家具有永久产出加成；领养伙伴 doro 会出现在桌面上并 +8% 产出。
- **日程表**：按时间添加提醒（每天 / 工作日 / 周末 / 仅一次，最多 20 条），支持延后 10 分钟；到点 doro 会说话 + 播放动作 + 弹系统通知，点击通知唤出宠物。
- **题库答题**：右键菜单 →「学习」进入题库。每日一题（答对 +100 / 答错不扣）、随堂小测 10 题（对 +100 / 错 -10）、随机刷题（对 +100 / 错 -10）、答题事件（对 +100 / 错不扣，冷却 20 分钟）、模拟考试（150 分钟 / 75 题，可续考）。默认题库「系统架构设计师」，可在题库面板切换，服务地址在配置中心修改。取题与判卷都在主进程，客户端拿不到答案。
- **自动更新**：局域网 Docker 静态源（`update-server/`，端口 9400）。每天 08:00 与启动后自动检查，托盘出现「发现新版本 vX，点击更新」后点击即下载并安装；也可在配置中心手动检查。
- **本地统计**：可选开启，记录累计天数、今日在线时长、会话次数，只存本机不上传。
- **配置中心**：动作频率（5–600 秒，默认 60 秒 ±25%）、自动散步间隔、宠物大小（70%–150%）、安全模式、音效、气泡 / 散步 / 穿透 / 置顶开关，支持恢复默认，改动即时生效并自动保存。
- **离线收益**：关掉以后再打开，按离线时长 5 折结算，最多结算 8 小时。
- **互动**：点一下摸头（掉 1~2 金币 + 台词）、双击贴贴、拖拽移动、**甩出去会带着惯性飞一段并反弹落地**、右键菜单换常驻动作。
- **自主漫游**：像 Shimeji 一样在桌面上走走停停、到边缘折返、朝向自动翻转；可调漫游速度，可选「跟随鼠标」。
- **全局快捷键**：`Ctrl+Alt+D` 显示/隐藏，`Ctrl+Alt+R` 把它叫到鼠标位置。
- **自动行为**：平时每隔 60 秒（可调）随机演一个动作；心情好爱演开心的，饿的时候只演惨的；「勿扰模式」下不表演、不说话、不弹提醒。
- **托盘**：喂饭 / 陪玩 / 换动作 / 置顶 / 点击穿透 / 开机自启 / 打开存档与日志 / 退出。
- **存档**：15 秒兜底自动存档 + 操作后防抖存档，白名单校验后原子写入。

## 快速开始

```powershell
npm install      # 安装依赖（含 Electron）
npm start        # 启动桌面宠物
npm run dev      # 带 DevTools 启动
```

首次启动会在屏幕右下角出现 doro，并在托盘生成图标。右键 doro 或左键点金币胶囊都能打开面板。

## 操作说明

| 操作          | 效果                                                                    |
| ------------- | ----------------------------------------------------------------------- |
| 左键单击 doro | 摸头：金币 +1~2、心情 +1.0、随机台词                                    |
| 双击 doro     | 贴贴动作                                                                |
| 按住拖动      | 移动窗口，播放走路动画                                                  |
| 右键 doro     | 打开菜单：喂饭 / 陪玩 / 升级 / 动作库 / 商城 / 日程表 / 配置中心 / 退出 |
| 点金币胶囊    | 展开账本面板（金币、产出、饱食、心情、累计、摸头次数）                  |
| 托盘图标单击  | 显示 / 隐藏                                                             |

## 数值一览

参数集中在 [`renderer/game.js`](renderer/game.js) 的 `BALANCE` 里，改完重启即可生效。

| 项目     | 数值                                       |
| -------- | ------------------------------------------ |
| 基础产出 | 等级 × 1 / 秒                              |
| 心情系数 | 1 + 0.5 × 心情/100（心情 100 时 ×1.5）     |
| 饱食衰减 | 0.25 点 / 分钟（约 6.5 小时掉完）          |
| 心情衰减 | 0.67 点 / 分钟                             |
| 喂饭     | 20 金币 → +30 饱食、+4 心情                |
| 陪玩     | 30 金币 → +25 心情                         |
| 升级     | `120 × 等级^1.35` 金币                     |
| 饿了     | 饱食 < 30 时产出 ×0.4；饱食 ≤ 8 时 ×0.2    |
| 离线     | 5 折，最多 8 小时，饱食/心情最低保留 30/25 |
| 咖啡     | 120 金币，10 分钟产出 ×1.5（可叠加时长）   |
| 招财猫   | 2000 金币，永久产出 ×1.1                   |
| 装扮     | 80 金币起，按动作库顺序每件 +20            |
| 主题     | 6000 / 10000 / 16000 金币                  |

## 打包

```powershell
npm run pack   # 免安装目录：release/win-unpacked/
npm run dist   # NSIS 安装包：release/doro_dz 桌面宠物 Setup 0.2.0.exe
```

安装包约 158MB（Electron 44 基线 + 49MB 动作资源），未做代码签名。

## 更新发布

`package.json` 的 `build.publish` 指向局域网更新源 `http://192.168.0.193:9400/updates`。
发布新版本的步骤：

1. 提升 `package.json` 的 `version`；
2. `npm run dist` 生成 `release/`（含 `latest.yml` 与安装包）；
3. 启动更新服务：`cd update-server && docker compose up -d --build`；
4. 客户端每天 08:00 自动检查，托盘「发现新版本」点击即自动下载安装。

详细说明见 [`update-server/README.md`](update-server/README.md)。

原始 `doro_dz/` GIF 未纳入 git（约 246MB），保留在本地用于重建资源。

## 存档与日志

- 存档：`%APPDATA%\doro_dz 桌面宠物\save.json`
- 会话标记：`%APPDATA%\doro_dz 桌面宠物\session.json`（用于识别异常退出）

托盘菜单里的「打开存档文件夹」「打开日志」可以直接定位。

## 素材处理

`doro_dz/` 里的 GIF 是白底，直接放到桌面上会带一个白框。整套流水线是：

```powershell
npm run assets:library   # 按命名表重命名源文件，生成 tools/action-library.json
npm run assets           # GIF → 透明 WebP + assets/actions.json
npm run assets:thumbs    # 生成动作库缩略图
```

`tools/prepare_assets.py` 会：

1. 把每帧最长边缩到 300px、WebP 质量 70，控制体积（295 个动作约 49MB）；
2. 从画布四边做洪水填充，只删掉与边缘连通的白色背景，保留 doro 身体内部的白色；
3. 对 alpha 做轻微羽化，避免锯齿；
4. 按所有帧的并集裁边，让不同动作里的 doro 看起来一样大；
5. 输出带透明通道的动画 WebP 和 `assets/actions.json`，并用待机帧生成托盘图标。

首次使用先装依赖：`pip install -r requirements.txt`。三个 `assets` 脚本都会自动寻找
`py -3` / `python` / `python3`，也可以用环境变量 `DORO_PYTHON` 指定解释器。

## 常见问题

**启动时报 `Sandboxed processes cannot read ... electron\dist`**

Windows 的某些数据盘（例如这台机器上的 `E:\`）没有给 `ALL APPLICATION PACKAGES` 授予读权限，Electron 的沙箱检查会拒绝启动。按提示给依赖目录补一次只读权限即可（只需执行一次）：

```powershell
icacls ".\node_modules\electron\dist" /grant "*S-1-15-2-1:(OI)(CI)(RX)" /T /C /Q
```

**doro 挡住了别的窗口？**

菜单 → 设置 → 打开「点击穿透」。开启后菜单会自动收起；鼠标只在 doro 本体、金币胶囊、账本面板和右键菜单上生效，其余透明区域直接落到桌面上。命中判定由主进程轮询光标完成（不依赖系统转发），如果哪天真的点不到，可以用托盘菜单里的同名开关关掉。

**想让它开机自启？**

菜单 → 设置 → 「开机自启」，或托盘菜单同名开关（写入系统登录项，可随时关闭）。
